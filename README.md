Typing-Game (Falling Letters)
A simple interactive reflex game built with C# Windows Forms for my Lab-2 assignment.

How it Works
Random Letters: Characters (A-Z) fall from the top at random positions.

Typing Challenge: You must press the correct key on your keyboard to catch them.

Dynamic Difficulty: The game gets faster every time you reach 5 points.

Scoring System: You gain points for correct hits and lose points if you miss or the letters hit the ground.

Tech Stack
Language: C#

Framework: .NET Windows Forms
